# 自動化実績まとめ

開発・試験・業務効率化のために行ってきた自動化の取り組みをまとめています。

---

## Windows アプリ + PLC による入出力試験の自動化
- Windows アプリから PLC を制御し、装置の入出力試験を自動化  
- 高信頼性が求められる装置で、数万回規模の繰り返し試験を実現  
- 長時間連続試験を自動化し、品質向上に寄与

---

## Excel VBA によるコード化・業務自動化
- Excel 上の管理情報から C 言語のテーブルを自動生成  
- 中間データから試験用データも自動生成し試験の一部自動化  
- 従来 5～6 人で対応していた作業を 1 人で対応可能にし、工数を大幅削減

---

## フリーツールによる操作繰り返し自動化
- マウス・キーボード操作の記録やスクリプト化による繰り返し操作の自動化  
- GUI 操作の繰り返し試験を自動化  
- 数百台の端末情報設定など、単純作業を自動化し作業時間を大幅削減

---

## Playwright + Python による Web 操作自動化
- Web UI の操作を Python で自動化  
- ログイン → 操作 → ログアウト → 別アカウントで再ログイン… の一連の流れを自動化  
- 深夜の特定タイミングで設定変更を行う運用を自動化し、無人化を実現  
- 手動では調整が難しい「夜中の操作/時間指定の確実な操作」を実現

---

## UiPath（学習）
- 業務では未使用だが、UiPath を学習  
- Web 操作・Excel 処理・ファイル操作などの基本フローを構築  
- RPA の考え方を理解し、他の自動化手法にも応用

---

## その他スクリプトによる自動化
- シェルスクリプト / teratermマクロ による環境構築の自動化  
- ログ解析アプリの作成 ※ログからシーケンス図を自動生成するツールなど  
- 状況に応じて柔軟に自動化を実施し、再現性と効率を向上
