# 対応ペリフェラル一覧

これまでに扱ったペリフェラルと、主な経験内容をまとめています。  
これらは主に OSレスマイコン開発時の実績です。  

| ペリフェラル | 用途の概要 |
|--------------|----------|
| UART         | 各種機器とのシリアル通信 |
| SPI          | 各種機器とのシリアル通信（マスタースレーブ方式） |
| I2C          | EEPROMの制御 |
| タイマ       | 周期割り込み |
| DMA          | 動画を画像として取り込み/保存画像の再生 |
| GPIO         | 入出力制御、割り込みトリガ、装置制御 |
| ADC      | 音声のデジタル化(録音用) |
| DAC      | 音声のアナログ化(再生用) |
| ウォッチドッグ | システム監視、リセット制御、誤動作時の復帰設計 |

## 共通の経験内容
- デバイスドライバ開発  
- 割り込み制御・優先度設計 ※要求仕様により多重割り込みを使用
