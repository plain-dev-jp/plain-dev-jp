# 組み込み・通信処理エンジニア ポートフォリオ

組み込みLinux・OSレス環境・通信処理を中心に、  
上流設計～実装～評価まで一貫対応してきたエンジニアのポートフォリオです。

本リポジトリでは、**私のスキル紹介**と**技術Tips**を中心にまとめています。

---

## 🧩 得意領域
- 組み込みLinuxのファームウェア開発（起動処理調整、アプリケーション開発）  
- OSレスマイコンのファームウェア開発（デバイスドライバからアプリケーション開発まで一貫して対応）
- C言語 を用いた低レイヤ開発(UART/同期式通信/SPI/IICなど)
- 各種通信プロトコルの実装・検証（HTTP/SSH/FTP/DHCP/DNS/TLSなど）

### ■ その他

#### ■ プロトコル関連
HTTP / SSH / FTP / DHCP / DNS / TLS など、多様なプロトコルの実装・試験を経験。  
※フルスクラッチではなく、OSSや既存モジュールの調整・拡張・デバッグを担当。

Wireshark を用いて用途・主要フィールドを把握し、通信ログから問題切り分けが可能。

---

#### ■ 自動化・ツール作成
Windowsアプリ＋PLC、Playwright＋Python、マウスキャプチャーリプレイツール、  
Teratermマクロ、装置内スクリプトなどを用いた試験・検証手順の自動化に対応。

また、RPAツール（UiPath）を個人環境で習得しており、  
基本的な自動化フローの構築が可能。

---

#### ■ Linuxユーザー空間 / カーネル境界の理解
procfs / sysfs / ioctl を用いた状態参照・設定変更・デバイス制御による装置挙動・通信処理の調査・切り分けを多数経験。
